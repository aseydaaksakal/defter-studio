    Kaynak: Claude Code oturum kaydındaki her model çağrısının gerçek token sayıları (girdi, önbellek okuma/yazma, çıktı, düşünme). Dolar, Claude Code'un kendi hesapladığı model fiyatıyla liste fiyatı karşılığıdır; abonelikte ödenmez, harcamanın göreli ağırlığını gösterir. İstem metinleri gizlilik için yazılmaz; istekleri saatinden tanıyın (İstanbul saati). Üretici: tools/token-rapor.py, her teslimde güncellenir.
